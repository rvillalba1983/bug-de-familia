# Propuesta de controles (pendiente de aprobar)

| Acción | Control |
|---|---|
| Moverse | Clic izquierdo en el destino, o WASD |
| Correr (hace ruido) | Mantener Mayús |
| Agacharse o ponerse a cubierto | C |
| Pausa táctica | Espacio |
| Interactuar | E, o clic izquierdo sobre el objeto |
| Convertir | Q y clic en el objeto o enemigo |
| Atacar | Clic derecho |
| Piezas del cuerpo | Tab |
| Responder preguntas | Teclas 1 a 4 o clic |
| Mapa | M |
| Menú | Esc |

Durante la pausa táctica el ratón selecciona objetivos y planifica acciones.
