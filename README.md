# Bug de Familia

Videojuego 2D de sigilo táctico e investigación para PC, con Godot 4.7.2. Proyecto privado.

## Probarlo
1. Descarga [Godot 4.7.2 estable](https://godotengine.org/download/archive/4.7.2-stable/) (edición estándar, no .NET).
2. Clona este repositorio.
3. En Godot, pulsa **Importar** y elige `project.godot`.
4. Pulsa **F5**.
